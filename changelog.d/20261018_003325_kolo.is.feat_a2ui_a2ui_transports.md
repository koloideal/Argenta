### Added

- `argenta a2ui` CLI command: runs an application as an A2UI agent with
  `--transport/-t`, `--port/-p`, `--socket-path`, `--verbose/-v` and
  `--reload/-r` (hot reload on file changes) options; transport can also be
  selected via `ARGENTA_A2UI_TRANSPORT`.
- New `Transport` implementations under `argenta.a2ui.transport`:
  `WebSocketTransport` (default, for browser clients), `SSETransport` and
  `LongPollTransport` (stdlib HTTP servers sharing `transport.http`
  infrastructure, proxy-friendly browser fallbacks), `SocketTransport`
  (JSON Lines over TCP or Unix sockets for native clients) and a live
  bidirectional `MemoryTransport` (`live=True`, `push()`/`messages()`) for
  embedding Argenta apps into host applications.
- Permanent browser example under `examples/example_a2ui`: a Lit client that
  connects over async-iterable transport connectors (ws → sse → poll
  fallback), renders the emitted surface with a scrollable fixed-height
  output card on top and command cards grouped `A2UIConfig.cards_per_row`
  per row.

### Fixed

- `argenta a2ui` shuts down gracefully on Ctrl+C and treats client
  connection resets (TCP RST on socket/HTTP transports) as normal drops
  instead of printing tracebacks.
