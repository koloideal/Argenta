### Fixed

- Registering a command whose trigger contains any whitespace character
  (tab, newline, carriage return, non-breaking space, ...) now raises
  `TriggerContainSpacesException`. Previously only the ASCII space was
  rejected, so such triggers were silently registered but could never
  be matched from user input.
