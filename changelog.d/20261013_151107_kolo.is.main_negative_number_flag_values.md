### Fixed

- Negative numbers can now be passed as flag values: `move --offset -5`
  yields `offset = "-5"` instead of an empty `offset` plus an unknown
  flag `-5`. Only tokens that look like a number (`-5`, `-3.14`) are
  treated as values; other dash-prefixed tokens still start a new flag.
