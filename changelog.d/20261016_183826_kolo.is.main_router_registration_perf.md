### Performance

- Command registration is ~2-3x faster: handler argument validation now
  reads `__code__`/`__annotations__` directly instead of running the
  `inspect.getfullargspec`/`inspect.get_annotations` machinery per handler
  (the `inspect` path is kept as a fallback for callables without
  `__code__`). Duplicate-name checks no longer build a union copy of all
  taken triggers and aliases per command, and trigger/alias names are
  normalized to lowercase once during validation instead of being
  re-lowered on every lookup table update.
