### Added

- `App` accepts `initial_message_font` and `farewell_message_font`: any FIGlet
  `.flf` font loaded with `FigletFontLoader().load(path)` from
  `argenta.app.presentation.ascii_art`. Fonts are validated eagerly —
  unreachable paths, malformed `.flf` files and fonts missing required glyphs
  raise `UnreachableFigletFontException`, `InvalidFigletFontException` and
  `MissingGlyphsException` respectively.
- `FigletFontLoader` transparently compiles `.flf` fonts into `.flfd` dumps
  for near-zero-cost loading, with stale/corrupted dumps falling back to
  re-parsing. Fonts can be precompiled via `FigletFontLoader.compile()` or
  the `argenta fonts compile` CLI command — useful when packaging
  applications as standalone binaries.
- `argenta fonts` CLI group: `fonts list` browses downloadable fonts from the
  community collections and `fonts fetch` (backed by `FigletFontFetcher`)
  downloads a font by name or URL, validates it and writes a compiled dump
  alongside.

### Removed

- The `art` runtime dependency. Banners are rendered by a built-in FIGlet
  parser from bundled `.flf` fonts with byte-identical output.
