### Added

- New `argenta fonts preview <font>` command renders the word "Argenta" in any FIGlet font — by name or direct `.flf` URL — so a font can be inspected before downloading it into a project.
- `FigletFontFetcher` now caches downloaded fonts in `$XDG_CACHE_HOME/argenta/fonts` (or `~/.cache/argenta/fonts`). Repeated `fonts fetch` / `fonts preview` calls for the same font are served from disk instead of hitting the network. The location can be overridden via the `cache_dir` constructor argument or the `--cache-dir` CLI option, and disabled via `use_cache=False` or the `--no-cache` flag. `FigletFontFetcher.fetch_cached()` resolves a font to its cached path without copying it anywhere.

### Fixed

- `argenta fonts fetch` no longer crashes with `InvalidURL` on font names containing spaces — names are now URL-encoded when building download URLs.
