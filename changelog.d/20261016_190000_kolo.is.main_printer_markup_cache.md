### Performance

- The default printer now caches parsed `rich.text.Text` renderables per
  unique string (LRU, 256 entries), so repeated prints of identical
  messages — most notably the command groups block under
  `repeat_command_groups_printing=True` — skip Rich markup parsing
  entirely. Command groups rendering is ~1.5-1.9x faster; app startup
  improves further on top of the earlier `highlight=False` change.
