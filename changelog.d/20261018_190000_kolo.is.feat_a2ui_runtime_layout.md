### Added

- Runtime-owned layout: the `App` emits semantic blocks (`BlockKind`: banner,
  startup messages, command groups, output, system, farewell, error) through a
  `Layout` protocol (`argenta.app.presentation`), and every runtime decides how
  they are separated. `App.prepare_for_run`, `dispatch_input_command` and
  `handle_input_error` take the runtime layout; `App.present_command_groups`
  presents the command list on demand.
- `argenta.repl.REPLConfig` — terminal layout of the REPL: `dividing_line`,
  `prompt_gap`, `frame_padding`, `startup_messages_gap`, `command_groups_gap`;
  passed as `Orchestrator.run_repl(app, config)`. `TerminalLayout` implements it.

### Changed

- **Breaking:** the dividing line moved from the `App` to the REPL runtime —
  `App(dividing_line=...)` is gone, use
  `Orchestrator.run_repl(app, REPLConfig(dividing_line=...))`.
  `StaticDividingLine`/`DynamicDividingLine` moved from `argenta.app` to
  `argenta.repl`; `DynamicDividingLine` gained `min_length`/`max_length`.
- **Breaking:** renderers return content without leading blank lines
  (`render_messages_on_startup`, `render_command_groups_description`, the plain
  farewell message) and render the dividing line markup via
  `render_dividing_line`; gaps are laid out by the runtime. The plain farewell
  is now preceded by a single blank line, like the rich one.
- **Breaking:** the A2UI `/log` data model is a list of structured entries
  (`{id, kind, text, markdown}`, one per block) instead of a single fenced
  string; the surface renders it with a templated `List`, so renderers own the
  separators and no terminal dividing lines reach the UI. `A2UIConfig` replaced
  `log_text_id`/`max_log_lines` with `log_list_id`, `log_entry_id`, `log_fence`
  and `max_log_entries`.
- `A2UIConfig` moved from `argenta.a2ui.models` to `argenta.a2ui.config`
  (`argenta.a2ui.A2UIConfig` is unchanged); `models` keeps the message types.
- Every `REPLConfig` and `A2UIConfig` field documents itself via
  `Annotated[type, "..."]` doc string; the API docs render bare field types.

### Removed

- `argenta.app.presentation.Viewer` and `App.viewer` — runtimes present blocks
  through their layout.
