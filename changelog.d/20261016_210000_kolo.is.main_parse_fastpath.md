### Performance

- `InputCommand.parse` is significantly faster: inputs without quotes or
  escape characters are tokenized with `str.split()` instead of the
  char-by-char `shlex` state machine, and repeated-flag detection is a
  name set lookup instead of a linear scan (O(n²) → O(n)). A typical
  command now parses ~7x faster; a 50-flag extreme input ~11x faster.
