### Added

- A2UI agent mode (protocol v0.9): `Orchestrator.run_agent(app, transport, config)`
  runs an application as an A2UI producer. A surface with one card per command
  and one input per flag (select, regex-checked text field or checkbox depending
  on `possible_values`) is emitted automatically; incoming `action` messages are
  converted back into `InputCommand`s and dispatched through the regular command
  handling path, so handlers need no changes.
- `argenta.a2ui` package: `AgentRuntime`, `A2UIConfig` (surface id, catalog id,
  protocol version, log path/size, theme — provided via `A2UIProvider` through
  the Dishka container context), `Transport` protocol with `StdioTransport`
  (JSON Lines over stdin/stdout) and `MemoryTransport` for tests and embedding.
- Handler `print()` output is captured into a `/log` data-model path shown in a
  log card on the surface; handler exceptions are reported into the same log
  without tearing the surface down.
