### Performance

- System message printing skips Rich's `ReprHighlighter`: the default
  printer now uses a console with `highlight=False`, so description blocks
  and framed output no longer run auto-highlight regexes over every print.
  Command groups description rendering is ~1.6x faster; app startup is
  ~1.3-1.6x faster as it prints the same block.
- `HistoryCompleter` caches the sorted candidate set (rebuilt only when
  history grows) and locates prefix matches via `bisect` instead of
  scanning and sorting all candidates on every keystroke.

### Changed

- The default console printer no longer auto-highlights numbers, URLs and
  paths inside system messages. Markup styling is unaffected; pass a
  custom `printer` to `App` if the previous behavior is needed.
