### Added

- Unit tests covering the whole `argenta._cli` package (`new`, `init`, `run`, `routes`, `info`, `build` commands and the entrypoint resolver); `_cli` is no longer excluded from the 100% coverage gate.

### Fixed

- Entrypoint resolution for `<dir>/__main__.py` paths whose parent directory is not a package: previously the resolver imported the process's own `__main__` module instead of the target file; it now imports the file as `<dir>.__main__`.
