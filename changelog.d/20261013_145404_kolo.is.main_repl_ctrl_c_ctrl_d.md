### Fixed

- Pressing Ctrl+C at the prompt no longer crashes the app with a
  `KeyboardInterrupt` traceback — the current input is discarded and a
  new prompt is shown. Ctrl+D (EOF, including end of piped stdin) now
  exits through the exit command handler instead of raising `EOFError`.
